# Okun relation for Germany with standard errors

Dependent variable: annual change in the registered unemployment rate (pp). Regressors: change in the output gap (pp) this year and last year, interacted with period dummies (base 1962-2006; 2007-21; 2022-25). HAC s.e. (2 lags). Cumulative response = sum of current and lagged gap coefficients; a negative value means unemployment rises when the gap falls.

## AMECO gap, 1962-2025 (N = 57)

| Period | Cumulative response | s.e. | 90 % interval |
|---|---|---|---|
| Base (to 2006) | -0.55 | 0.09 | -0.69 to -0.40 |
| 2007-21 | -0.29 | 0.10 | -0.46 to -0.13 |
| 2022-25 | -0.33 | 0.02 | -0.37 to -0.29 |

Difference 2022-25 minus base: +0.22 (s.e. 0.09). With four annual observations and three own parameters, the 2022-25 standard error is not reliable; the restricted model below uses one.

Restricted model (2022-25 differs from the base by one common shift in the current and lagged slope, no own intercept): cumulative response base -0.55 (s.e. 0.09); 2022-25 -0.35 (s.e. 0.07); difference +0.20 (s.e. 0.12).
